What to try first

  1. Set cap height to 1.4 mm → Rule 7(2) screening finding.
  2. Set it to 2.5 mm → inconclusive: the interval straddles the limit.
  3. Keep 1.4 mm, switch scale source to mono_metric → the same measurement can no longer sustain a violation.
  4. Set panel to 200×300 mm → the threshold jumps to 4 mm and 3 mm now fails.
  5. Set unit symbol to gms, or clear the tax clause.
  6. Set packing date to 2020-06-01 → the unit-price rules vanish.

Reading the result

Every run compares the measurement against what the renderer actually drew. If within interval is ever false, the metrology is wrong — that is the check that makes the millimetre claim falsifiable.
