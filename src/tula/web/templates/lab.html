Why the lab is a separate place

A compliance system that mixes demonstration data into casework cannot be trusted with either. TATVA keeps the separation in four places at once:

  • Storage — every record carries a source of inspection or bench; they are never summed together.
  • Analytics — Dashboard counts, compliance rate, trend and district coverage all read operational records only unless the bench dataset is explicitly selected here.
  • Product history — a bench run against a GTIN never appears in that product's operational history, so a generated label cannot manufacture a shrinkflation signal.
  • Labelling — a bench run is marked Test bench in every listing and on its own record page, so a generated label cannot be mistaken for casework at a glance.

The equivalent assertions also run headless under pytest tests/test_bench.py, so the matrix on screen and the test suite cannot drift apart.
